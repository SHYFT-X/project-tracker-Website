Core architecture

Four levels. Zero confusion.

Every asset lives inside a clean Miller Columns hierarchy, so anyone on a project can drill down from a campaign to a specific draft in seconds — no hunting through folders or email threads.

Level 1

Projects

Top-level campaign or property buckets — e.g. Branding & Identity, Mobile App Redesign.

Level 2

Deliverables

Asset categories within a project — e.g. UI Mockups, Logo Variations, Video Trailers.

Level 3

Creative Requests

Specific task briefs with deadlines, priority, and specs.

Level 4

Versions & Proofing

Iterative drafts — v1.0, v2.0 — attached to a request for client review.

What it does

Core features

Visual Proofing & Pin-Point Annotations

Click anywhere on an image, video frame, PDF deck, or slide to drop a numbered pin. Each pin links to a comment thread — no more "make the text bigger" ambiguity.

Version Control & Comparison

Automatic iteration history from v1.0 through final approval, with a side-by-side diff view and one-click Approve or Request Changes.

Role-Based Access & Workspaces

Streamlined Client view, a full-management Admin / Project Coordinator workspace, and a SuperAdmin panel for multi-tenant oversight and branding.

Collaboration & Real-Time Syncing

Schedule sync meetings, follow a live chronological audit trail, and get WebSocket notifications the moment a new version or comment lands.

End-to-end workflow

From brief to approval

  1. 1

    Submit Request

    A user creates a request specifying deliverable type, priority, and due date.

  2. 2

    Upload Initial Draft

    The design team uploads v1.0 for review.

  3. 3

    Drop Visual Feedback

    The client or reviewer clicks on the proofing canvas to drop numbered pins with revision requests.

  4. 4

    Upload Iteration

    The team updates the design and uploads v2.0.

  5. 5

    Compare & Approve

    The client compares v1.0 vs v2.0 side-by-side and marks the version Approved.

Built for every seat at the table

Roles & workspaces

Client View

A clean, streamlined portal to review assets, leave pin comments, approve deliverables, and schedule sync calls.

Admin / Project Coordinator View

Full management workspace to upload new versions, manage trash/recycle bins, create project categories, and assign team members.

SuperAdmin View

Platform oversight to manage multi-tenant client organizations, user permissions, and custom branding.
