# My Website (Static Starter)

Simple responsive static website scaffold. Open index.html in a browser, or run a local static server.

Run locally (examples):

PowerShell / Command Prompt:
python -m http.server 8000

Then open: http://localhost:8000

Or with Node (if you have npx):
npx serve

Files added:

- index.html
- styles.css
- script.js
